# Rental records: foundation and acceptance boundary

DOM-01a adds authoritative unit records, immutable proposed lease versions, retained human-recorded execution evidence and separately recorded occupancy. It extends the Convex CRM and existing signed workforce gateway; it introduces no parallel orchestration engine.

## Implemented behavior

- Units derive ownership from an authorized existing property. Labels have a normalized per-property identity and an explicitly entered valid IANA time zone; neither location nor jurisdiction is inferred.
- Lease versions retain tenant/landlord references, start/end calendar dates (including explicitly open-ended terms), exact non-negative minor-unit amounts, recorded currency/frequency/payment terms, deposit facts, source notes and recording provenance. No balance, valuation, penalty or statutory deadline is calculated.
- Amendments create immutable versions. A new proposal does not replace the recorded executed terms or rewrite an existing occupancy's original version.
- Execution recording requires an authenticated authorized actor, fresh revision/proposal reference, explicit signature/terms attestation and a current accepted, clean-scanned document belonging to a recorded tenant in exactly the workspace. The evidence freezes file digest/revisions and terms digest. **This is an entered attestation, not cryptographic signature verification, legal validity or proof of human presence.** No signature request or contract commitment is sent. Computer-mediated human-decision enforcement remains a separate release gate.
- Occupancy starts independently from execution. Source changes, conflicting recorded term dates, an existing current occupancy, stale versions and invalid relationships hold new occupancy work. Move-out records an observed fact and source note; it does not calculate deductions, deliver notice or terminate a legal agreement. Future observed signature/move-in/move-out dates are refused using the recorded unit day. Planned work is not treated as observed occupancy.
- Every mutation revalidates authenticated scope/membership and relationships. Explicit team/brokerage scopes resolve only currently permitted organization-owned spaces; affiliated private desks remain excluded. By-ID foreign and corrupted related references return not found. Nonces/signing, narrow inquiry-job grants and existing operating bindings are preserved.
- Actor/workspace-scoped command receipts bind the complete operation payload. Identical retries return their original record result; changed payloads fail. Revision checks reject stale concurrent writes. Audit events retain actor, revision, time and content fingerprint. New proposals are refused at the bounded unit-history limit; no historical records are deleted to make room.
- `rentals.list` and `rentals.history`, and Chippi's existing `chippi_crm_query` operations `leases` and `leaseHistory`, expose bounded scoped pages of readable property/unit/party facts and entered versions. They preserve proposal/execution/occupancy distinctions, changed/missing evidence, overlapping terms and actionable next steps. Storage object keys and private access credentials are omitted. Complete protocol references remain internal tool handles; customer-facing conversational/rendered acceptance is still required. New lease write operations are not available through the agent gateway.

## Exact verification

**37 new isolated Convex in-memory domain/integration cases** pass. A personal endpoint flow actually saves unit → proposed lease → human-recorded execution fixture → move-in → amendment → move-out, with immutable versions/events, exact retries and zero email outbox/workforce jobs. Separate team and brokerage cases save/read organization-owned proposals through the real signed-gateway handler, prove private-record exclusion and revoke membership before another read. Accepted documents/scans are synthetic fixture records; actual upload/scan/signing providers were not invoked.

Fault cases cover changed/missing source evidence, scan failure, digest/revision/request mismatch, unrelated document parties, foreign properties/parties/units/versions, corrupt occupancy references, invalid money/dates/roles, duplicate identity, stale edits, concurrent amendments/move-ins, revoked access, missing authentication, bounded history/pagination, invalid references and forbidden agent execution writes. The latter cannot silently expand a failed reference into a broader scan. Scoped history preserves old recorded facts.

Initial domain selection **20/20**; expanded selection **23/25** (two team fixtures omitted the existing required `leadId`); corrected **25/25**. Later selected regressions **175/175** and **177/177** overlap the final run. Three actual future-observation refusal assertions initially **0/3**, retained. Corrected domain **34/34** includes those refusals and the UTC/local-day counterexample; units now explicitly store time zones, so this is not represented as an identical-schema paired baseline. The original synthetic flow's future move-out was corrected to an observed past date; its persistence/idempotency oracles remain. Final domain selection **37/37** is included in the full application run.

**Full web unit/in-memory integration: 1,028/1,028**, zero failed/skipped tests/suites, process exit 0. Initial root-cwd invocation reported 1,023 passing assertions but failed a grid filesystem suite before its tests; it is preserved as **failed**, not a clean run. Corrected supported web-cwd run **1,025/1,025**, followed by final **1,028/1,028** after the last guards/cases. Existing long-future `convex-test` timer-overflow warnings remain; these tests do not certify scheduler/provider/endurance correctness. The separate accurate evaluation scheduler work is preserved.

**Agent contract checks: 33/33**, including two new mocked-HTTP transport cases that preserve scoped read arguments through the existing adapter. These are not coordinator/delegation or real-model trials. Web/Convex TypeScript, scoped ESLint, agent Biome and whitespace checks pass. Initial web typing narrowed the bridge's actual response shape; a formatter invocation failed on the absent optional Tailwind plugin, then formatted only new TypeScript files through the installed parser without installing dependencies or touching UI/vendor files. Negative setup/type results are retained.

Commands use the existing web/agent Vitest runner with one worker, full web `tsc --noEmit`, Convex `tsc --noEmit`, six-file ESLint, scoped agent Biome, offline Convex code generation and `git diff --check`. No application/customer database migration, hosted Convex deployment, account seeding, real model/provider call or financial/outbound effect was performed.
